# Three-bin coherent query and bounded local-noise protocol

This protocol is specified before these new results. It follows the existing two-bin experiment and preserves all earlier files. It is not externally preregistered or an experiment on light or IBM hardware.

- Use the original cavity-dimension-2 instrument, with system dimension8. Construct retained trace-preserving flagged instruments at absolute Choi cutoffs0.03 and0.003. Preserve discarded-weight and right-normalization diagnostics. These are approximations to a truncated cavity model, not converged optical physics.
- Compile the one-bin isometry to generic all-to-all `u,cx` gates with Qiskit optimization level1 and seed13. Retain independent flag/environment registers for all3bins. Expect15 or18 circuit qubits, depending on cutoff.
- Check the ideal coherent preparation against direct channel propagation for every one of8 histories: unnormalized branch matrices, probabilities, normalized conditional system states, trace and positivity. Check original-cavity-2 versus retained-model errors separately.
- For last-bin click and all-three-click predicates, implement one full amplitude-amplification round. Check all history probabilities against the analytical selected/unselected rescaling and all conditional system states against the retained target. Report selected mixture errors as well as individual branches. No local-reflection approximation is introduced.
- Compare classical complete8-branch calculation and event-specific recursion. Last-click and all-click event probabilities/conditional states admit linear-in-bin-count channel recursion and require no exponential history enumeration. Draw100,000 exact conditional histories from the3bin table with no rejection. Record reproducible local timing repetitions as classical CPU measurements, not quantum-hardware timing.
- Separately simulate only7/8qubit **one-bin** compiled preparation and one full amplification round with exact density matrices. After each`u`gate apply local depolarization strengthλ_CX/10; after each`cx`gate apply two-qubit strengthλ_CX, for λ_CX in[0,1e-5,1e-4,1e-3]. These are declared generic channels, not measured device errors. Aer parameterλ means E(rho)=(1−λ)rho+λ I/2^n locally.
- Apply independent asymmetric final flag readout, P(record1|flag0)=0.01 and P(record0|flag1)=0.02. Condition the system state using the corresponding mixture of true-flag branches. Report both acceptance and conditional-state trace distance to the correct retained target; an increased click count alone is not success. Also report results before readout mixing.
- Dense matrix noise simulation is forbidden above8qubits. Bound each worker to2048MiB and each case to240s; terminate and preserve a diagnostic if a limit is hit. Do not duplicate a live job. Ideal3bin simulation may use statevectors up to18qubits. No ideal full18qubit operator or density matrix is constructed.
- Record source/protocol/version hashes before the run; preserve failures and partial cases. Implementation tolerance1e-8 applies to circuit-versus-retained-model checks, not to truncation errors or chosen gate-noise cases.
- Explain register growth, generic gate costs, unmatched preparation/readout/routing resources, and the distinction between a numerical conditional density matrix and physically preparing that state. No computational or sensing advantage is assumed.
