# Time-varying effective-drive diagnostic: before-run specification

This is an exploratory synthetic follow-up explicitly implementing the amplitude-schedule item in LASER_DIAGNOSTICS_ROADMAP.md. Existing studies and finals artifacts are unchanged. The drive Ω in `0.5 Ω (sigma+ + sigma-)` is an effective field-amplitude/Rabi-frequency proxy in arbitrary inverse-time units. Under a fixed dipole/coupling geometry, intensity is proportional to Ω²; +20% field is +44% intensity, not +20% energy. No absolute wavelength, incident photon budget, physical sensor bandwidth or wafer transfer function is supplied.

Use the original emitter–defect–cavity model at cavity dimension 4, bin duration 1, 96 bins per reset record. Retain the conditional physical state across every source/detector change; never reset at a schedule transition. A source step has unknown onset uniformly in bins 16–48 inclusive. A telegraph source starts low, begins switching at bin 16, and switches with probability .06/bin. Its average post-start dwell is 16.67 bins, with no seconds interpretation. Latent schedules are saved for scoring but never supplied to inference. All generators are piecewise constant within a bin.

Four independently seeded complete pipelines each use separate: (a) 10,000 one-photon calibration trials for efficiency and 20,000 dark-only bin trials; (b) 128 baseline response records, selecting Ω from [1.1,1.3,1.5] by training likelihood; (c) 128 baseline and 128 source-training records (half step, half telegraph) for classical baseline fitting and training-only fractional drive selection from [.10,.20,.30]; (d) 256 null threshold-calibration records; and (e) 128 held-out records per declared scenario. Calibration trials are idealized independently controlled inputs, not measured hardware characterization; all other physical parameters are assumed known. Account for their count separately. A reduced separate-seed software smoke run is not evidence and cannot tune the main design.

Pre-main software review found that adjacent master seeds plus integer offsets would reuse some training streams. Before any main evaluation, replace all offsets with explicit purpose namespaces mixed by NumPy SeedSequence, separately naming measurement, source-schedule, nuisance-onset, HMM-fit and detector-calibration streams. Save the full namespace/seed table and assert every actual seed is unique across all pipelines and the summary bootstrap. The original smoke output is preserved as a software check, not independent scientific evidence. A second software smoke verifies this correction. No held-out main result existed when it was made.

The physical inference model computes exact causal forward likelihoods for a baseline, an unknown-onset step and a hidden telegraph schedule by retaining unnormalized quantum density matrices for each classical source regime. Source alternatives have equal mixture weights. Class prior baseline/source is 1/2 each. The known schedule *distribution* is an experimental design assumption; actual schedules and nuisance labels are hidden. Fit only the candidate fractional drive on source-training records. Compare a three-state classical HMM trained separately on baseline/source labels (three EM starts, 400 iterations, training-only refinement), and an absolute causal difference between adjacent 16-bin count windows. All three receive identical held-out bits. HMMs capture classical history; they are not an IID strawman. Physical structure and extra calibration are supplied to the quantum-state model, so this is no computational or quantum-sensing advantage test.

Each method's statistic is its maximum over the full 96-bin record: prefix alternative/baseline log-likelihood ratio for physical/HMM models, absolute local count contrast for the count method. Thresholds use independent null maxima and the conservative finite order statistic for nominal 5% record-level false alarms, with strict exceedance. No threshold is tuned on holdout. First alarm stops detection; alarms before a source change are failures, not successful early detection. Report detection within 32 bins for records with a true onset and at least 32 bins of follow-up, prealarms, missed events, and restricted delay with misses/prealarms charged all 32 bins. Report no-event/late-onset denominators explicitly. This is causal onset detection, not a real-time device latency measurement.

Held-out scenarios are fixed before first evaluation: stable baseline; +20% source step; +20% source telegraph; +10% step; faster .20/bin telegraph; efficiency loss; dark-count increase; emitter detuning step; cavity-loss increase; onset of one-bin detector dead time; onset of 10% next-bin afterpulsing; combined detector changes; +20% source step plus independent efficiency loss. Nuisance onset is independently uniform 16–48. Source-changing and source-stable counterfactuals remain separately labeled. Non-source drift is never scored as a correct source diagnosis. Afterpulse events are additional classical detector flags; their likelihood is not included in the nominal trained model, deliberately testing mismatch. A blind dead-time bin evolves the physical unconditional channel.

Report nominal false alarms, detection, honest delay, collected binary-click counts, predictive log score, and causal drive-estimate bias/RMSE (also the zero-change estimate). Prediction of Ω is conditional on the assumed family; it does not identify cause uniquely. Record-level paired comparisons and a hierarchical bootstrap resample the four pipelines then their independent records. Four pipeline clusters provide limited calibration-variation precision; report per-pipeline values and do not claim calibrated coverage. No multiple-comparison discovery claims. Preserve all cases, raw bits, latent schedules, calibration/training arrays, seeds, first-run source hashes, runtime and model failures.

Independent tests must cover exact finite-history normalization, marginalization over all source paths, state retention, asymmetric detector readout including afterpulses, forbidden adjacent detections under dead time, and threshold ties. Compare cavity-4 and cavity-5 schedule predictions on fixed deterministic probes; dimension 5 is a sensitivity check, not an exact physical reference. Run bounded local jobs with one BLAS thread, preserve actual process handles, and no cloud/API use. Broader continuous spectral diffusion, thermal/multimode fields and hardware afterpulse timing remain separate work.
