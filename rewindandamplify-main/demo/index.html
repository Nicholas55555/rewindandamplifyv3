A quantum recurrent state machine emits a click, or no click, at each step. A click at one chosen step is rare, so most runs tell you nothing about it. Change the build and watch what happens to 48 runs of the machine. Everything here is simulated exactly in your browser.

On a real chip: on IBM’s ibm_kingston, 3 steps, steer + local reached 0.87 with 40 two-qubit gates, and textbook Grover 0.59 with 213. This page simulates the same circuits with a simple noise model.

Find a table from a vague request

A classical step turns the request into catalogue keywords. A reader reads them one at a time, turning the phase of each entry that contains them. Grover turns phase into probability, and an entry that matches only part of the request gets only part of the boost.

A plain scan of 16 names is far faster than this. The oracle here is compiled from the catalogue, so classical code has already read every entry. This shows the architecture; it is not a speedup.

Built for the FGCU Quantum Hackathon (IBM Qiskit Fall Fest, November 2026). The machine is theta 0.6, gamma 0.2, phi 0.45, zeta 0.3. The noise line is a simple estimate that treats any gate error as scrambling the run; the full results use IBM device noise models.
