# Optical controls: faithful small circuit emulations

Specified before running these adapters, 11 November 2026. All existing source and results remain unchanged. This module does not submit jobs or access an IBM account. The parent hardware campaign owns native compilation, calibration, shot allocation and execution.

## Atomic finite-pulse channel

Use the canonical `laser_sensor_viability/model.py` parameters: two 2.5 ms pulses separated by 20 ms free evolution, phases zero and pi/2, T1=100 s, T2=0.2 s, 1% preparation error. Driving Rabi frequency is pi/(2*pulse duration) times sqrt(relative intensity); the declared power light shift acts during pulses only. Build each constant-drive Lindblad superoperator, exponentiate it, and compose the three channels. Extract Kraus operators from its Choi matrix and synthesize the full two-column Stinespring isometry. This represents the channel for arbitrary input states, not a rotation chosen to reproduce one output probability. The ground state is computational 1, excited state 0, consistent with the canonical Bloch ground z=-1 convention.

Independently check all six Pauli eigenstate inputs against an affine Bloch exponential and compare canonical measured probabilities after separately applying its 2%/4% readout model. The circuit includes a purification of preparation error, but does not inject a synthetic readout error into hardware counts. Provide both ideal Born and canonical synthetic-readout targets. Export Z at detunings -5,-0.5,0,+0.5,+5 Hz, a short-T2=0.02 s control and 10% relative-intensity change, plus X/Y checks at +0.5 Hz. Hardware noise is additional to the deliberately modeled channel. Optical time parameters are simulated parameters, not circuit execution times or optical wavelength validation.

## Photon interferometer and exposure moments

Encode each photon's path in one qubit and its loss destination in another. This is a first-quantized representation restricted to the symmetric photon subspace: identical one-particle phase and beamsplitter operations act on every factor. Aggregated mode occupancies, not photon labels, are the observable. A two-photon NOON input is the symmetric state (|aa>+|bb>)/sqrt(2); the incoherent control is purified with a separate environment. Apply the actual per-photon path phase and balanced beamsplitter. Independent symmetric loss is a beamsplitter into vacuum modes: each path becomes a superposition of its surviving and corresponding lost mode. Keep those loss registers until final measurement. Decode vacuum, one- and two-photon outcomes without postselecting loss away. A separate source-success flag charges failed preparations as vacuum attempts.

Validate against an independent second-quantized Fock-space beamsplitter and binomial loss Kraus calculation, not just the published cosine formula. Check total photons, all six number-resolved probabilities, and first/factorial-second moments. These are one normalized output-mode moments; the 32-cell exposure study's spatial scaling is separate. No repeated phase-point experiment is treated as free simultaneous illumination. No resist activation, blur or material response is realized by the circuit.

## Coherent reference and truncation

The canonical product coherent input has one mean photon in each input arm. Global optical phase is unobservable for this number-conserving interferometer and photon-count measurement (including phase-insensitive loss), so it is equivalent for this task to a Poisson(mean=2) mixture of total-number sectors. Sector N is the symmetric product of N identical path-superposition states, not N independent occupied input modes. Prepare and propagate that actual state through the same phase, beamsplitter and loss transformations. Export N=1,...,8; N=0 is an explicitly charged deterministic-vacuum reference, needing no hardware shot. Keep original, unnormalized Poisson weights and an explicit missing-tail outcome. Bound any aggregate-count event error by P(N>8). Report first/second photon-moment tail contributions separately: a probability tail bound alone does not bound unbounded moments. No conditional renormalization may silently remove omitted photons.

Use phase 0.35 and 0.35+pi at eta=0.81 to expose the NOON pi ambiguity and show that the coherent reference distinguishes the branches. NOON controls additionally cover phase0,pi/4,eta=0.48, preparation success0.1, and incoherent mixture. Both incident sample arms are charged; each successful pair has two input photons before transmission/detection. The encoded loss eta combines the canonical object and detection efficiency, while the metadata keeps their separate values. These circuits emulate optical statistics on superconducting hardware; they generate no propagating optical photons.

## Delivery and interpretation

Export an ordered `logical.qpy`, one classical register named `meas`, a `ra-hardware-bundle-v1` manifest with compact references and full ideal computational-basis probabilities in NPZ, source hashes, and register decoding. Validate ideal circuits, serialization round trip and independent physics before submission. Generic gate counts are compiler estimates, not native routed hardware costs. Retain every predeclared case, including errors and rejected circuits. The parent may classify an expensive circuit as a resource-limited component rather than implying full-study execution.

This protocol does not repeat the 128-second online diagnostic benchmark, finite-shot phase estimation, or a physical optical experiment. No new quantum advantage or unknown defect identification is assumed. A subsequent separately specified local phase/loss/dark-count identifiability test may be added; it must not alter these frozen circuit targets based on hardware results.
